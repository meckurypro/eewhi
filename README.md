# Eewhi Technical Solutions website

A responsive, static website built with HTML, CSS and a small amount of vanilla JavaScript. There is no backend, database, build step or environment configuration.

## Deploy to Vercel

1. Extract this ZIP file.
2. Put the contents of this folder in a Git repository, or import the folder into Vercel.
3. Choose **Other** as the framework preset if Vercel asks.
4. Leave the build command and output directory empty/default (the site is served from the project root).
5. Deploy.

You can also use Vercel CLI from this directory with `vercel`.

## Pages

- `index.html` — main company website
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `assets/styles.css` — responsive visual design
- `assets/script.js` — mobile navigation and footer year
